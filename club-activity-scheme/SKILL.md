# 社团文体活动方案生成

## 概述

把"依据体卫艺开学工作检查表整理文体活动资料"这一重复性工作固化为流程：批量生成两类文档（均为公文格式 Word），并分类归档到知识库。

核心产出两类文档，可单独或一起做：
- **第一类（方案）**：各社团活动方案 + 全员文体活动计划及实施方案（一份，只覆盖当前学期，不跨到下学期）
- **第二类（计划＋名单）**：各社团活动计划 + 各社团学生名单（学生来自各班花名册，每人最多参加 4 个社团）

## 你的工作方式

按以下阶段推进。若只做第二类，可直接跳到 Phase 2B。

### Phase 1：确认需求与社团清单

从用户描述或上传的检查表中提取：
- 检查表要求（重点看"全员文体活动"块：每天一节体育课、每天综合体育活动≥2小时、课间15分钟、大课间30分钟、全员文体活动计划实施方案、组建体育/美育/特色社团）
- 社团类型清单（体育类、美育类、特色类各有哪些社团）
- 活动时间范围（默认当前秋季学期，如 2026年9月—2027年1月；用户若说"只用到X月"则以 X月 为截止，不要跨到下学期）
- 落款日期（用户指定，如 2026年9月10日）
- 活动时间若涉及课后服务，统一写"课后服务时间"

若用户未明确，读取 `references/school-profile.md` 获取学校实际情况（学校名称、领导小组、指导老师分工、班级），并向用户**确认一轮**：社团清单、时间范围、落款日期、指导老师分工。

### Phase 2A：生成社团方案与文体活动方案

```bash
python3 scripts/generate_schemes.py
```

脚本说明（编辑 `scripts/generate_schemes.py` 顶部 CONFIG 区与 CLUBS 列表）：
- **CONFIG 区**：学校名称、落款日期、领导小组、指导老师、学期时间范围与活动表
- **CLUBS 列表**：每个社团的名称、简介、目标、时间地点、指导老师、四阶段活动内容等
- 生成"XX社团活动方案"（若干份）+ "全员文体活动计划及实施方案"（1份）
- 输出默认 `/sandbox/workspace/shetuan_output/`，按社团类别分子目录

### Phase 2B：生成社团活动计划与学生名单

```bash
python3 scripts/generate_plans_rosters.py
```

脚本说明（编辑 `scripts/generate_plans_rosters.py` 顶部 CONFIG 区）：
- **CONFIG 区**：学校名称、落款日期、`MAX_CLUBS`（每人最多社团数，默认4）、活动时间、CLUBS 列表、`ROSTER_FILES`（各班花名册文件与解析方式）
- 花名册解析：脚本内置 3 种解析函数（`parse_xls_107` / `parse_xls_108` / `parse_xlsx_109`）。**遇到新格式的文件，按同样的模式新增一个解析函数，并在 `PARSERS` 与 `ROSTER_FILES` 中登记**；花名册常有多张表且名单不一致，优先取"正式花名册/全校学生名单"这类权威表
- 分配规则：每个学生随机参加 2—`MAX_CLUBS` 个社团，优先分配给人数少的社团使各社团人数均衡；脚本末尾会校验"单个学生最多参加社团数 ≤ MAX_CLUBS"
- 生成"XX社团活动计划"+"XX社团学生名单"各若干份，输出到 `OUT/{社团类别}/`

### Phase 3：存入知识库分类归档

1. 确认目标知识库（用户说"个人知识库"则用其 kb_id；不确定时用 `search_knowledge_base` 查找）
2. 若不存在，用 `create_folder` API 创建分类文件夹：主文件夹「社团文体活动资料」＋子文件夹 体育类社团 / 美育类社团 / 特色类社团
3. 上传各文档到对应类别子文件夹（方案、活动计划、学生名单按社团所属类别归类；全员文体活动方案放主文件夹）
4. 上传后告知用户归档结果

上传工具（二选一，均需先确认 IMA_OPENAPI 环境变量已配置）：
- `upload-to-kb` 技能的 `upload_to_kb.py`（支持 `--folder-id`）
- `ima-knowledge` 技能的 `upload_file.py`

### 多轮修改

- **时间范围调整**（如从学年改为学期）：修改"全员文体活动方案"的时间表，重新生成并上传新版本；**告知用户旧版本需在 IMA 客户端手动删除**（知识库 API 不支持删除）。
- **社团增删**：在 CLUBS 列表中增删条目，重新运行。
- **学生名单按真实选社调整**：默认是均衡随机分配，若有指定名单，替换分配逻辑或直接改学生名单后重新生成。

## 公文格式规范

- 标题：方正小标宋简体 二号（22pt）居中
- 正文：仿宋_GB2312 三号（16pt），首行缩进 2 字符
- 一级标题（一、二、…）：黑体 三号
- 二级标题（（一）（二）…）：楷体_GB2312 三号
- 行距：固定值 28 磅
- 落款：单位名称 + 日期，右对齐

## 文档结构

- **社团活动方案**：活动目标 → 领导小组及职责 → 活动时间与地点 → 工作原则 → 活动内容与安排（四阶段）→ 社团评价（含一票否决制）→ 工作要求
- **社团活动计划**：活动目标 → 时间与地点 → 社团成员（人数）→ 逐月活动安排表 → 活动要求
- **社团学生名单**：表格（序号｜姓名｜性别｜班级）+ 人数，附活动时间、指导老师

## 示例

### 示例 1：生成全部社团方案并归档
用户说"依据检查表整理文体活动资料，体育类有篮球、羽毛球、乒乓球、排球、跳绳，美育类阅读、音乐、美术……"
→ Phase 1 确认清单与日期 → Phase 2A 运行脚本 → Phase 3 建文件夹并上传。

### 示例 2：按花名册生成活动计划与学生名单
用户说"每个社团还要有活动计划和学生名单，学生来自三个班，每人最多参加4个社团，活动时间课后服务"
→ Phase 1 确认班级与花名册文件 → Phase 2B 运行脚本 → Phase 3 分类上传。

### 示例 3：只调整时间范围
用户说"文体活动方案时间搞到下个学期了，只用到 2027 年 1 月"
→ 修改脚本时间表 → 重新生成 → 上传新版本 → 提醒删除旧版。

## 资源目录

- `scripts/generate_schemes.py` — 生成社团活动方案 + 全员文体活动方案
- `scripts/generate_plans_rosters.py` — 生成社团活动计划 + 学生名单（含花名册解析与分配）
- `references/school-profile.md` — 学校实际情况（领导小组、指导老师分工、班级）
