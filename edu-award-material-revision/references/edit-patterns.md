# 修改模式与技术要点

## 一、典型修改模式

| 修改类型 | 做法 |
|---------|------|
| 全局改名（申报类别、单位、称号） | `rep_all(doc, 旧, 新)`，覆盖所有段落与单元格 |
| 精确改某字段（教龄、年限、电话） | 先 `lc(row)` 去重得到逻辑单元格，再 `rep_cell(单元格, 旧, 新)`，避免误伤同值的其他格 |
| 删整行（超期工作量、超期荣誉） | `del_row(table.rows[i])`；多行从后往前删，避免索引位移 |
| 删某段（超期事迹段落） | `p._element.getparent().remove(p._element)` |
| 改落款日期 | `rep_all(doc, 旧日期, 新日期)` |

## 二、年份/年限倒推（把材料整体回退 N 年）

站在新的时间基准点上，重新计算：

- **教龄 / 乡村工作年限 / 班主任年限**：`原年限 - N`。如回退 2 年：31→29、14→12。
- **日期**：年份 - N。如回退 2 年：2026年9月→2024年9月、2026年09月04日→2024年09月04日。
- **删除超期内容**：新基准之后尚未发生的事件、尚未获得的荣誉，全部删除。
  - 删除荣誉列表里"≥新基准年"的行。
  - 删除工作量表中晚于新基准的学年行（如基准 2024 年 9 月，删除 2024-2025、2025-2026 两行，保留至 2023-2024）。
  - 删除正文里"20XX年位列第X名""20XX年获评X"等超出基准的句子。
- **固定事实不动**：出生日期、参加工作时间、籍贯、身份证号等与基准年无关，不改。

## 三、技术陷阱

1. **跨 run 替换**：Word/WPS 常把一句话拆成多个 run（尤其含中英文/数字时）。直接改单个 run 会漏。`rep()` 已做"先逐 run、后整段兜底"，整段兜底会把全部文本压进首个 run，可能丢失段内混合格式——因此优先让逐 run 命中，必要时才兜底。
2. **合并单元格**：`row.cells` 会按网格展开，合并格重复出现。必须用 `lc(row)` 去重，再按"逻辑列序号"定位值单元格（如信息表：逻辑列 1=值1、3=值2）。
3. **单元格内换行**：如"从事班主任\n工作14年"，直接匹配"从事班主任工作14年"会失败。应匹配跨换行的片段（如"工作14年"）或按段落逐段替换。
4. **中文路径写坏 docx**：某些环境 `doc.save()` 写中文路径会产生非法 zip。必须用 `save_doc()`（先存英文临时名再 `os.rename`）。
5. **重复写**：修改脚本每次应 `shutil.copy` 原件再改，保证可重复运行（幂等）；直接在已改文件上二次删行会导致重复删除。

## 四、意图陷阱

1. **申报类别 vs 历史荣誉**：只改"申报奖励名称/推荐类别/标题/公示/鉴定意见"处的类别名；荣誉列表中候选人历史获得的称号是事实，保留。判断：出现在荣誉/获奖列 → 保留。
2. **口语转写的模糊表述**：如"时间往前面推"未给幅度，需从上下文（如"搞2024年的材料"、教龄"三十一→二十九"）推导出 N=2，并在交付时说明依据。
3. **删"某年及以后"要彻底**：同一超期事实可能在申报表500字事迹、2000字事迹材料、鉴定意见、目录、汇总表事迹等多处出现，需逐个文件清理。

## 五、真实案例（可作为模板）

**任务**：把一套「2026年·衡东县优秀班主任」材料，改回「2024年9月·衡东县优秀乡村教师」。

**改动清单**：
- 类别名"优秀班主任/优秀乡村老师"→"优秀乡村教师"（封面、汇总表推荐奖励名称、事迹材料标题、公示、鉴定意见、佐证材料、目录、材料目录）。
- 日期"2026年9月"→"2024年9月"、"2026年09月04日"→"2024年09月04日"。
- 教龄 31→29、乡村工作 31→29、班主任 14→12（申报表信息表 + 汇总表）。
- 删除申报表荣誉行"县优秀乡村老师 2024年9月"。
- 删除工作量"2024-2025""2025-2026"两行。
- 删除事迹（500字/2000字/鉴定意见）中"2024年第3名、2025年第4名、今年创新高""2024年获评优秀乡村教师"等超期内容。
- 删除佐证材料目录中"2024年荣获衡东县优秀乡村教师称号"行。
- 保留荣誉列表中 2021、2023 年的"县优秀班主任"（历史事实）。

对应脚本见本技能 Phase 3 的 `docx_inplace.py` 用法。
