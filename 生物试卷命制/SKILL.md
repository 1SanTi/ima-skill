# 生物试卷命制

依据教师命题需求，结合教材、课标、教辅点题与真题，命制一份结构规范、题源可溯、经过同题创编的初中生物学试卷，产出"试卷／答案／细目表"三份 Word，并归档知识库。

## 适用场景

- 教师口述或书面给出命题需求（范围、题型、题量、分值、特殊要求），要求据此出卷。
- 教师圈定了教辅／真题中的具体题目，要求**同题创编**（不照抄，改变选项或表述）后组卷。
- 需要按会考／学考结构命制单元卷、模拟卷、期中期末卷、专题卷。

## 输入要素（尽量四项齐全）

| 要素 | 说明 | 缺失时 |
|------|------|--------|
| 命题需求 | 范围（册／单元／章／节／课时）、题型、题量、分值、时长、难度、改编要求 | 必问 |
| 教材 | 对应版本教材（如人教版八上第六章） | 检索知识库"01-课程标准与教材" |
| 课标 | 《义务教育生物学课程标准（2022版2025修订）》对应概念／内容要求 | 检索知识库 |
| 题源 | 教辅点题清单（页码＋题号＋考点＋题型）或真题；教辅/教材 PDF（含扫描版） | 依口述考点创编 |

## 工作流

### Phase 0 · 需求解析
1. 若需求为**录音／语音**，先转文字，逐条提取：范围、题型、题量、分值、时长、难度、来源题目清单、改编比例与方式。录音中"第X页第X题"要逐题记录其**考点与题型**。
2. 列成"命题任务清单"，与用户确认关键歧义（范围、分值结构、改编比例）。

### Phase 1 · 素材检索（并行）
- 教材：定位到具体章节课时，提取教材原文关键表述与结构名称（命题不得超出教材表述）。
- 课标：提取对应"大概念—内容要求—学业要求—学业质量"条文，作为命题依据与素养立意来源。
- 真题／教辅：提取题型风格、情境素材、设问方式，供改编参照。
- 参考既有成果：检索知识库"04-试卷设计"下用户已有试卷／细目表／答案，**保持版式与风格统一**。

### Phase 1.5 · 题源提取（当题源为扫描版教辅/教材时）
- 读取 `references/source-extraction.md`，按流程：判断 PDF 形态 → 定位页码 → 逐页读取原题 → 提取原书插图。
- **插图优先直接取自原书**（用 `scripts/crop_figures.py` 渲染页面并按相对坐标裁剪），不要自行绘制；仅当原书无对应图时才用 `plot_figs.py` 绘制。
- 裁剪后必须用 `fetch` 视觉复核：图形完整、标注齐全、无题干文字混入。

### Phase 2 · 结构设计
- 读取 `references/exam-structure.md`，按会考结构定卷面（选择题、非选择题分值比）。
- 将题源清单逐项"定位"到 → 节／课时 → 知识点 → 题型 → 素养 → 难度，形成细目表初表。

### Phase 3 · 同题创编
- 读取 `references/adapt-rules.md`，按比例改编：**约20%调选项顺序、约15%题型创新（题型与原题不一致而考点不变）、其余改表述**；严禁照抄原题。
- **紧贴原题**：题干情境与素材尽量保留原貌，改编幅度以"改一改选项/表述"为度，而非另起炉灶。
- 选择题答案分布力求均衡（A/B/C/D 大致各 6～7 个）。
- 非选择题按空、按点赋分，分值加总须与卷面一致；开放性设问"答出其一、合理即可"。
- 需要识图／示意图时，优先用 Phase 1.5 提取的原书插图；确无原图时用 `scripts/plot_figs.py` 绘制（中文标注用 Noto Sans CJK SC）。

### Phase 4 · 三卷产出
- 用 `scripts/build_paper_docx.py` 生成三份 Word：**试卷卷／参考答案及评分标准／命题多维度细目表**。
- 细目表列：题号｜试卷结构及题目类型｜考查知识（核心考点）｜素材来源（对应原题）｜改编方式｜核心素养｜难度系数，并附"命题设计说明"。
- **排版**：读取 `references/layout-rules.md`，采用"选择题左文右图、图片缩小、控制在 8 页以内"的打印友好版式。
- 校验：题号连续、图片数量、分值加总、答案数、答案分布；**转 PDF 数页数并检查图片不越界**。

### Phase 5 · 归档
- 读取 `references/kb-archive.md`，将三份文档上传到"中学生物命题设计与分析"知识库对应文件夹（**试卷与答案分开成文**）。
- 命名规范：`第X章《章节名》单元测试卷.docx`、`…参考答案及评分标准.docx`、`…命题多维度细目表.docx`。

## 关键规范

1. **题源可溯**：每道题在细目表中标明对应原题（教辅页码题号／模拟考），实现"题源可溯、考点可查"。
2. **紧贴原题、取用原图**：题干情境与原书插图尽量直接沿用，改编只"改一改选项/表述"，不另起炉灶、不自行画图（除非原书无图）。
3. **改编比例**：20% 调序／15% 题型创新／其余改表述，具体见 `references/adapt-rules.md`。
4. **课标对标**：命题严格对照课标内容要求，不超纲；素养立意（生命观念／科学思维／探究实践／态度责任）。
5. **版式统一**：与用户知识库中既有试卷保持一致（卷头、注意事项、题型说明语、标注格式）。
6. **答案独立**：试卷与答案分文件，避免同文件混排。
7. **难度**：单元测试卷预估难度系数约 0.68～0.70；会考模拟卷约 0.65。

## 脚本

| 脚本 | 作用 |
|------|------|
| `scripts/crop_figures.py` | 从扫描版教辅/教材 PDF 提取插图：`render` 渲染页面、`crop` 按相对坐标裁剪并生成校验总览 |
| `scripts/build_paper_docx.py` | 数据驱动的三卷生成模板；复用只需替换 CHOICES／NONCHOICE／META／ANSWERS 数据区 |
| `scripts/plot_figs.py` | 绘制眼球、耳、反射弧、关节等示意图（原书无图时的备选） |
