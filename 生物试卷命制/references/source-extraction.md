# 题源提取规范（扫描版教辅/教材 → 原题 + 插图）

当教师圈定的题目来自**扫描版**教辅（如《学法大视野》）或教材 PDF 时，按以下流程把"原题文字"与"原书插图"提取出来，供命题使用。

## 一、判断 PDF 形态

```python
import pymupdf
d = pymupdf.open(pdf)
print(d.page_count, len(d[0].get_text()))
```
- `get_text()` 有内容 → 电子版，可直接抽取文字与内嵌图片。
- `get_text()` 为空、每页仅 1 张图 → **纯扫描件**，需渲染成图片后用视觉模型读页。

## 二、定位页码

1. 渲染前几页（目录页）确认**书内页码与 PDF 物理页的对应关系**（常见为 `物理页 = 书内页 + 偏移`，偏移由目录页/正文首页页脚页码确定）。
2. 按章节目录（如"第六章 人体生命活动的调节 …P1"）确定目标页区间。

## 三、逐页读取题目

- 渲染目标页为 PNG（170~200 dpi）。
- 用 `fetch(type="file_path")` 读取页面图片，提问：
  "完整转述本页所有题目：板块名称、题号、题干、全部选项；并描述插图内容与位置。"
- 逐页记录：题干、选项、答案线索、情境素材、对应页码题号。

## 四、提取插图（关键）

**优先直接取用原书插图**，不要自行绘制。

1. **拿到插图的相对坐标**：对每一页提问——
   "请找出本页所有插图（图形/照片/表格），逐一列出：①内容；②在整页中的边界框[左,上,右,下]，用0~1小数表示。"
   （模型目测坐标有 ±0.03 误差，只能作初值。）
2. **用连通域分析精修坐标**（推荐）：
   - 对页面做 Otsu 二值化 + 连通域分析；
   - 按连通域尺寸区分"文字类"（小连通域）与"图形类"（大连通域/长线条）；
   - 沿 y 波段列出文字行与图形块的包围框，把裁剪边精确落在"正文末字"与"图形标注"之间的空隙里。
3. **裁剪**：用 `scripts/crop_figures.py` 的 `crop` 子命令（含 padding、2× 放大、生成 overview 校验图）。
4. **视觉复核**：用 `fetch` 读取裁剪图（或 overview 拼图），确认"图形完整、标注齐全、无题干文字混入、无残缺"，不合格则调整坐标重裁。
5. 验收标准：图形主体 + 所有标注数字/引线 + 图内文字（如"图2""甲""乙"）齐全；**不含页面上的题干、选项、解析等正文文字**。

## 五、可接受的取舍

- 若两幅小图共用一个图注（如两张耳机照片共用"图1"），分别裁剪时各自保留其专属图注，不必强求公共图注。
- 原图本身为"半身/示意"画法（如下肢未绘全）属原书设计，不算裁剪缺陷。
- 表格（如血流量表、接诊汇总表）建议在 Word 中**重建为规范表格**，比截图更清晰。
