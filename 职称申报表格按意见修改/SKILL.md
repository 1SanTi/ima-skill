# 职称申报表格按意见修改

## 适用场景

用户给出一份**已填写**的教师职称申报表格 + 一段修改意见（常含口语、口语化指令），要求"在原表上修改、不要调整原表格式"，改完还需分类归档到知识库。

## 核心红线

**只在原文件、原表格上改内容与对齐，不重建表格、不重新排版。** 字体、字号、边框、合并单元格、列宽、行高保持原样。所有改动通过"改单元格文本 / 重写单元格段落 / 改对齐"完成。

## 工作方式

### Phase 1：解析修改意见 → 待改点清单
把口述/文字意见逐条整理成"改什么 / 怎么改"。意见常是口语，要结合表格原文本推断真实意图，例如：
- "申报职称用全称" → "高级" → "中小学高级教师"
- "考核成绩一般是合格，培训结果是结业" → 培训表两列口径互换/归位
- "信息技术是 2.0" → 项目名补"2.0"
- "任职工作经历居中" → 该栏内容水平+垂直居中
- "多凑点字" → 指定业绩栏扩写
- "再加一个 XX，至少两个才能加分" → 指导青年教师等栏补足人数

### Phase 2：定位文件与单元格
1. 用 `scripts/docx_table_reviser.py <file>` 打印段落、表格行列、每单元格文本（含合并去重）。
2. 重点确认**合并单元格的网格坐标**：`table.cell(r,c)` 对合并区返回同一对象；表头标签格与内容格往往相邻（如 r,c=标签，r,c+1=内容）。先探查目标格的段落数、run 数、字体，再动手。

### Phase 3：就地修改
用 `scripts/docx_table_reviser.py` 的函数编写修改脚本（每次 `shutil.copy` 原件再改，保证幂等可重跑）：
- `rep(p, old, new)` / `rep_cell(cell, old, new)`：段内/单元格内文本替换，保留格式（先逐 run 后整段兜底）。
- `rewrite_cell(cell, lines, align=..., valign=...)`：**保留首段/首 run 字体格式**重写整格文本，支持多段换行与水平居中(CENTER)、垂直居中(center)。用于"扩写业绩""改口径""补人名"。
- `save_doc(doc, out)`：中文路径先存英文临时名再改名，规避 zip 写坏。

### Phase 4：读回核对
修改后读回，逐单元格与**原件对比**，确认：
- 只有预期单元格发生变化（合并格的重复网格位都会显示新值，属正常）；
- 结构未变（行列数一致）；
- 统计扩写栏的字数增减，向用户报告。
必要时 `soffice -env:UserInstallation=file:///tmp/louser --headless --convert-to pdf` 转 PDF 目视检查排版无溢出。

### Phase 5：分类归档到知识库
确认目标知识库（多为个人知识库），在"帮别人做职称/申报材料"类文件夹下归档；文件名可加"（修改版）"与原件区分。

## 常见改法经验库

| 意见 | 改法 |
|---|---|
| 申报职称用全称 | "高级" → "中小学高级教师"（中小学教师系列规范名） |
| 单位名称 | 用全称，勿漏"第"字（如"衡南县九中学"→"衡南县第九中学"） |
| 培训/继续教育表 | "考核成绩"一般填"合格"，"培训结果"填"结业" |
| 信息技术 | "信息技术应用能力提升工程" → "…工程 2.0" |
| 工作经历居中 | 该格水平居中 + 垂直居中；去掉制表符，改用全角空格分隔 |
| 业绩栏"凑字" | 师德师风、班主任、指导青年教师等栏扩写（见下） |
| 指导青年教师加分 | 一般需 ≥2 人；不足则补人（补写"指导 XX 教师…"条目） |
| 时间格式 | 统一 YYYY.MM，连接符统一（"至" / "—"） |

## 扩写原则（重要）

- 可参考知识库中**同类申报材料/事迹材料**的行文风格与句式，但**事实必须与本人一致**，严禁把他人（如其他候选人）的事迹、奖项、数字张冠李戴搬入。
- 用"通用师德/工作描述 + 表格中已出现的事实"扩写；不编造具体奖项、事件、名次。
- 补人（如新增"王宁"）若缺具体事迹/获奖，用中性表述（指导其钻研教材教法、参加教研与公开课等），并在交付时提示用户核实补充。
- 交付时明确说明哪些是扩写表述、需按实际核对。

## 输出规范：中文标点（重要）

生成或修改职称/公文类文档时，**标点一律使用中文全角标点**：

- 引号必须是**中文弯引号** `“ ”`（不能是英文直引号 `"`）；单引号 `‘ ’`。
- 逗号、分号、冒号、问号、叹号、括号、书名号、破折号一律全角：`，；：？！（）《》——`。
- 序号点用全角 `1．` 或顿号 `1、`，不用半角 `1.`。
- 例外**保留半角**：小数/日期中的点（如 `2009.9`）、百分号 `%`、“次/分”的斜杠 `/`（属计量符号，非标点）。
- 用 `scripts/punct_fix.py <file.docx>` 一键修复（直引号自动配对转中文弯引号、序号点转全角）。
- 生成后**务必复查**：扫描文档文本中 `ord(ch) < 128` 且非字母数字空白的符号，应只剩 `%`、`/` 等可保留项。

## 资源

- `scripts/docx_table_reviser.py` — 自包含工具：open_doc/save_doc/rep/rep_cell/lc/rewrite_cell/set_valign，可命令行自检文档结构。
- `scripts/punct_fix.py` — 中文标点修复：直引号→中文弯引号（自动配对）、序号点→全角，可命令行运行。
- `references/case-table4.md` — 本次《表4 职称公示表》真实案例改动清单。

## 注意事项

- 知识库写入不可逆（无删除 API），上传前确认文件夹与文件无误。
- 涉及真实人事信息，改后必须读回核对；不臆造未提供内容。
