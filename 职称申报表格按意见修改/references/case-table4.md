# 真实案例：《表4 湖南省中小学教师系列专业技术职称申报参评人员情况公示表》

## 背景
申报人：李敏（云溪县第九中学，体育，申报中小学高级教师）。表格为 26 行 × 22 列的合并单元格表，
右半区"任现职以来主要工作经历和业绩"下分主要工作经历（R01–R05）、教学工作（R06–R13）、师德师风主要业绩（R06–R13, 21列）、
班主任工作经历和业绩（R14–R20）、指导青年教师经历和业绩（R14–R20, 21列）、继续教育（R21–R25）。

## 用户修改意见 → 实际改动

| 意见 | 改动位置 | 改法 |
|---|---|---|
| 申报职称用全称 | 封面 P2 run | "高级" → "中小学高级教师" |
| （顺带修正）单位全称 | 封面 P2 run | "云溪县九中学" → "云溪县第九中学" |
| 考核成绩一般是合格 | 培训表 R23–R25 第 8 列 | 优秀/良好/优秀 → 合格 |

| 信息技术是 2.0 | R24 项目名称 | "信息技术应用能力提升工程" → "…工程2.0" |

## 关键单元格定位（合并格）
- 主要工作经历内容：`table.cell(1, 16)`（col16–21 与 R01–R05 合并）
- 师德师风内容：`table.cell(6, 21)`（R06–R13 合并）
- 班主任内容：`table.cell(14, 16)`（R14–R20）
- 指导青年教师内容：`table.cell(14, 21)`（R14–R20）
- 培训表：项目名 `cell(24,0)`、机构 `cell(23,2)`、考核成绩 `cell(r,8)`、培训结果 `cell(r,13)`

## 经验
1. 封面是"整段多 run"，用 `rep(p,'高级','中小学高级教师')` 逐 run 命中即可，勿整段重建。
2. 合并格用 `table.cell(r,c)` 取其一即可；改后所有覆盖网格位自动同值，核对时看到"多行同变"属正常。
3. `rewrite_cell` 自动克隆首 run 的 rPr（含宋体 9pt），扩写后字体不变。
4. 扩写参照知识库同类事迹材料的行文风格，但事实严格对应本人，未编造具体奖项；新增"王宁"条目用中性表述并提示核实。
5. 校验：与原件逐格 diff，仅预期格变化；结构 26×22 不变；PDF 渲染无溢出。
