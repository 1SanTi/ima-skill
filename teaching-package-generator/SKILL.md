# 教学授课资料一体化生成（AI 课程包生成器）

将教师"讲课口述录音 + 教学设计笔记"一键生成完整的授课资料包：**教学授课简案、教学设计、教学逐字稿、课件制作脚本、课件 PPT** 五份成果，并把全流程沉淀为可复用的 Skill。

## 触发词

口述转课程、讲课录音生成、生成授课资料包、生成简案+教学设计+逐字稿+课件、AI 课程包、授课全案生成、教学设计全流程、口述备课

## 适用场景

- 教师/讲师提供讲课口述录音（MP3/WAV/M4A 等）与教学设计笔记（笔记、PDF、Word），希望生成完整授课资料包。
- 需要把不准确的 AI 概念、政策表述、领导人讲话引用**统一修正为权威准确表述**。
- 需要把一套完整备课流程固化为 Skill 以便复用。

## 输入要求

1. **录音**：讲课口述音频（内容不限，建议 30～90 分钟）。
2. **笔记**：教学设计笔记（note_id）或政策/素材清单笔记。
3. **可选**：配套参考 PDF（如《智能体设计模式》等专业书籍）。
4. **知识库**：用于检索权威文献的知识库（kb_id），尤其要包含领导人讲话原文、国家政策文件原文。

## 核心工作流（六步）

### Step 1：收集素材
- 用 `speech-to-text` 技能转录音频（faster-whisper，中文用 `small` 模型 + `beam_size=1` + `int8`，低内存环境可行；若网络不畅设 `HF_ENDPOINT=https://hf-mirror.com HF_HUB_DISABLE_XET=1`）。
- 用 `fetch` 读取笔记（note_id）、PDF（file_path）。
- 梳理现有教学设计的结构、教学目标、环节与表述。

### Step 2：检索知识库权威文献
针对三类内容**必须**用 `search(source="kb")` 检索权威原文，禁止凭模型记忆直接引用：
1. **领导人讲话原文**（如习近平总书记讲话）——必须 fetch 到全文，逐字核对。
2. **国家政策文件**——必须确认准确文件名、发布部门、文号、年份。课程主题涉及"AI 减负 / 教师减负"时，优先引用**教师减负政策**：中共中央办公厅、国务院办公厅《关于减轻中小学教师负担进一步营造教育教学良好环境的若干意见》（2019 年 12 月，核心金句"教师的主业是教书育人"）+ 教育部办公厅《关于进一步减轻中小学教师非教育教学负担若干措施的通知》（教师厅〔2025〕2 号，8 条措施）。不要默认套用学生心理健康政策。
3. **专业概念**（如智能体 Agent、LLM、Skill、MCP）——以权威书籍/报告定义为准。

### Step 3：核对与修正（关键步骤）
建立"原始表述 → 修正表述"对照表，逐条修正不准确内容。常见修正清单（务必核对）：

| 原始（常见错误） | 修正（权威依据） |
|---|---|
| 习近平总书记"三问"（当机器开始思考，我们应该何去何从 / 当 AI 参与治理，安全如何保障 / 数字鸿沟如何弥合） | 习近平总书记"时代之问"**四问**：①当机器开始思考，人类如何与之相处？②当算法参与决策，安全如何保障？③当技术挑战伦理，治理如何跟上？④当鸿沟不断拉大，普惠如何实现？（出处：习近平《携手构建公正合理的全球人工智能治理体系——在2026世界人工智能大会暨人工智能全球治理高级别会议开幕式上的主旨讲话》，2026年7月17日，上海） |
| 理念表述 | 习近平总书记核心理念是"以人为本、向上向善"，并提四点意见：坚持开放共赢、强化风险意识、鼓励包容并蓄、倡导和衷共济 |
| 《智能体的设计逻辑》 | 《智能体设计模式：智能系统构建实战指南》（Jimmy Song，2025年9月） |
| "人工智能+教师"专项行动 | 《"人工智能+教育"行动计划》（教育部等五部门）+《教师生成式人工智能应用指引（第一版）》（教育部） |
| 《2025年版本中小学教师人工智能生成使用指南》 | 《教师生成式人工智能应用指引（第一版）》+《中小学生成式人工智能使用指南（2025年版）》 |
| AlphaGo 预测蛋白质（口误） | AlphaFold 预测蛋白质结构（2024年诺贝尔化学奖） |
| 大模型"猜词"（口语） | 大模型本质是"基于统计预测生成最可能的词序列" |
| LLM＝智能体（错误） | LLM 是智能体的"认知引擎"，本身不是智能体；完整智能体＝LLM＋Skill/MCP＋记忆 |

⚠️ **修正原则**：凡是无法从知识库核实到原文的引用（如"某院士说……""某具体数学猜想"），一律改用稳妥、可追溯的表述，或直接删除，绝不臆造。

### Step 4：生成四份文字文档
按以下顺序、以下规格生成（Markdown，均输出到 `/sandbox/workspace/output/`）：
1. `01_教学授课简案.md` —— 一页纸：目标（认知/观念/技能三维）、重难点、四板块流程表、理论支撑权威引用、结尾引用。
2. `02_教学设计.md` —— 完整版：课程信息、学情分析、三维目标、重难点与突破策略、理论支撑（分维度列权威文献）、分板块教学过程（含教师活动/学员活动/设计意图）、板书主线、教学评价、风险预案、附录文献清单、**修正说明对照表**。
3. `03_教学逐字稿.md` —— 口语化完整讲稿，可直接照读；领导人讲话、政策文件名、专业概念处严格按原文。
4. `04_课件制作脚本.md` —— 逐页分镜：页码、标题、版式、正文、配图、动画、讲师备注；并给出风格与配色建议。

### Step 5：生成课件 PPT
用 `ima-ppt` 技能：
- 按课件脚本逐页生成 `slide_XX.html`（1280×720，命名必须 `slide_` 下划线 + 两位数字）。
- 视觉锚点建议：Swiss/International（清晰严谨，适合教学），配色 60-30-10（浅色背景 + 深青标题 + 青绿强调），不用蓝紫渐变、不用 Inter/Roboto。
- 用 `python3 /sandbox/workspace/skills/ima-ppt/scripts/ima_html_to_ppt.py -d <slides目录>` 转成 `output.pptx`。

### Step 6：交付
- 将五份成果整理到 `/sandbox/workspace/output/`，用 `provide_file` 提供下载链接（尤其 PPTX 与四份 Markdown/Word）。
- 在交付说明中，**明确列出修正了哪些不准确表述**，方便用户复核。

## 注意事项

- 转录音频若本地 whisper 安装失败，优先 `faster-whisper`（依赖 CTranslate2，不依赖 torch CUDA），并设 HF 镜像与 `HF_HUB_DISABLE_XET=1`。
- 低内存（<4GB）环境：whisper 用 `small`/`base` 模型 + `beam_size=1`，避免 OOM。
- 权威引用是本流程的**最高优先级**，宁缺毋滥、宁删毋错。
