# 文档格式套用（docx-format-styler）

## 这个技能做什么

用户手上常有两份 Word：一份格式规范（如已定稿的新闻稿），一份格式杂乱（默认五号字、标题没加粗）。本技能会自动识别"规范文档"里标题与正文的**字体、字号、加粗、首行缩进**，一键套用到"待改文档"，同时完整保留后者的文字内容、段落结构、对齐方式和图片。

## 输入

- **参考文档（--ref）**：提供格式模板的那份。
- **目标文档（--target）**：要被修改的那份。
- **输出路径（--out）**：结果写到新文件，**绝不覆盖原件**。

## 工作流

1. **定方向**：确认哪份是"参考"、哪份是"目标"。用户说"按第一个改第二个"时，第一个是参考。若用户没指明、或两份都可能，用 `ask_user` 确认一句。
2. **跑脚本**（见下）。脚本自动识别参考文档的标题格式（字号最大的段落，居中/右对齐者优先）和正文格式（正文字号出现最多者），再套用到目标文档。
3. **看识别结果**：脚本会打印识别到的标题/正文字体字号。检查是否合理——正常情况下**标题字号应大于正文字号**；若两者相同，脚本会提示，改用 `--title-pt/--body-pt` 手动指定。
4. **抽查验证**：用 `check_format.py` 或人工核对输出文档（见"验证"）。
5. **交付**：用 `provide_file` 把输出文件给用户。

## 命令

```bash
python3 scripts/format_doc.py \
  --ref "参考文档.docx" \
  --target "目标文档.docx" \
  --out "输出/目标文档（已排版）.docx"
```

可选覆盖（当自动识别不准时）：

```bash
  --title-pt 20   # 标题字号（磅）
  --body-pt 16    # 正文字号（磅）
  --font 宋体      # 字体名
```

## 关键规则

- **对齐方式不套用，只改字体字号缩进**。目标文档原有的居中、右对齐一律保留。参考里的居中标题、目标里的居中标题/右对齐副标题，都套用"标题格式"——这符合常规新闻稿（主标题 + 副标题两行都按标题处理）。
- **加粗以参考文档为准**。参考正文不加粗，则目标正文里的零星加粗也会被统一去掉，确保"完全一样"。
- **只动格式，不动内容**：不改文字、不删段、不动图片、不碰页眉页脚。
- **输出到新文件**，文件名加"（已排版）"等后缀，便于对照。

## 两个高频坑（脚本已处理，改动脚本时务必保留）

1. **图片 CRC 损坏**：微信 / WPS / 编辑器导出的 docx，内嵌图片常有坏 CRC，导致 `python-docx` 打不开整个文件（报 `BadZipFile: Bad CRC-32`）。`patch_zip_crc()` 把 CRC 校验替换为空操作即可绕过；保存时会重算 CRC，输出文件正常。**不要因为读不了就以为文件坏了。**
2. **加粗值可能是 `"false"`**：`w:b` 的 `w:val` 不一定是 `"0"`，也可能是 `"false"`。判断加粗要两种都兼容，否则会把"明确取消加粗"误判成"加粗"。

另外：**脚本文件名不要叫 `inspect.py`、`types.py` 等标准库同名文件**，否则运行时会遮蔽标准库、导致 `lxml` 等第三方库导入失败。

## 验证

不要只看 `python-docx` 的 `font` 对象（它可能返回继承值），直接读底层 XML 更准：

```bash
python3 scripts/check_format.py "输出.docx"
```

人工核对要点：
- 标题段：`eastAsia`/`ascii` 字体名一致、`w:sz`=**40**（半磅值，40÷2=20 磅）、存在 `w:b`。
- 正文段：`w:sz`=**32**（16 磅）、`w:ind` 的 `firstLineChars=200`（首行缩进 2 字符）、无 `w:b`。

## 示例

**示例 1｜新闻稿统一**
参考"云溪县霞流镇中学…新闻稿.docx"（标题宋体 20 磅加粗居中，正文宋体 16 磅缩进 2 字符），目标"秋光为序启新程…docx"（全篇默认五号）。以新闻稿为参考套用，目标的主标题（居中）与副标题（右对齐）都套标题格式，正文统一为 16 磅缩进 2 字符。

**示例 2｜公文统一**
用户："把这份工作总结改成和这份通知一样的字体字号。" → 以通知为参考执行。

## 边界情况

- 参考文档只有图片、没有文字段落 → 无法提取格式，脚本报错退出；让用户换一份含文字的参考文档。
- 标题与正文字号相同、无法区分 → 用 `--title-pt/--body-pt` 手动指定。
- 目标文档某段是居中引文而非标题 → 会被当作标题套用大字。若发现，事后单独微调该段。
