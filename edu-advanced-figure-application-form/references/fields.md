# 申报表字段规范与修正规则

整理候选人信息时对照本文件。字段名与 `scripts/fill_form.py`、`scripts/generate_attachments.py` 的 JSON 数据结构一致。

## 字段清单

### 封面
| 字段 | 说明 |
|------|------|
| 姓名 | 与身份证一致 |
| 申报奖励名称 | 使用通知规范全称，四选一：衡东县优秀教师 / 衡东县优秀班主任 / 衡东县优秀教育工作者 / 衡东县优秀教研团队 |
| 工作单位全称 | 完整全称，如「衡东县蓬源镇中学」，民办学校需注明「民办」 |
| 填报时间 | 如「2026年9月」 |

### 基本信息
| 字段 | 填写要求 |
|------|----------|
| 性别 / 民族 | 男/女；民族全称如「汉」 |
| 出生日期 | 公历阿拉伯数字，如「1972年8月」 |
| 籍贯 | 「XX省（自治区、直辖市）XX市（县）」，如「湖南省衡东县」 |
| 政治面貌 | 中共党员 / 群众 等 |
| 身份证号码 | 18 位，作为文本保留 |
| 参加工作时间 | 如「1995年9月」 |
| 学历/学位 | 如「本科」 |
| 教龄 | 如「31年」 |
| 现任行政职务及级别 | 无则留空 |
| 任现行政职务时间 | 无则留空 |
| 专业技术职称 | 如「中小学一级教师」 |
| 是否乡村教师/农村学校工作时长 | 如「是，农村学校工作31年」；否则「否」 |
| 是否班主任/工作年限 | 如「是，14年」；否则「否」 |
| 是否学前教育/特殊教育/民办教育/职业教育 | 是/否 |
| 是否学校班子成员（管理岗位）工作年限 | 是/否（或留空） |
| 教师资格证号 | 按证书填写 |
| 工作单位 / 联系电话 | 全称 + 手机号 |

### 列表型字段（JSON 数组）
- `工作简历`：`[时间, 所在单位, 从事工作]`，从参加工作填起，最多若干行。
- `荣誉`：`[获奖名称, 获奖时间, 授予单位]`，不超过 8 项。
- `教学工作量`：字符串数组，每项为「任教学校、年级、课程及课时」；学年度在原表中已预填（如 2021-2022 至 2025-2026），JSON 里无需再写学年度，按顺序对应即可。
- `先进事迹`：一段文本，不超过 500 字，第三人称，突出师德、业绩、贡献。

### 其余附件字段（generate_attachments.py 使用）
- 汇总表（附件4）18 列：`序号`、`姓名`、`工作单位`、`性别`、`民族`、`出生年月`（如 197208，六位数字）、`政治面貌`、`学历`、`行政职务及年限`（无则空）、`专业技术职务`、`教龄`、`乡村工作时间`、`班主任时间`、`推荐奖励名称`、`人选类型`（如「教师（初中）」）、`电话`、`100字事迹`、`民主测评满意率`（通常留空待单位填写）。
- 征求意见表（附件5）：`职务`（无行政职务可填「教师」）。
- 事迹材料（附件6）：`事迹标题`、`综合表现`（400 字内，不含个人姓名等基本信息）、`主要业绩`（1600 字内，第三人称，可用 \n 分段）。

## 常见扫描/手写识别错误修正

| 类型 | 错误示例 | 修正 |
|------|----------|------|
| 单位名 OCR 错字 | 遵源中学 | 蓬源中学 |
| 荣誉名称错字 | 县优秀乡村老师 | 县优秀乡村教师 |
| 籍贯省称省略 | 湖南衡东 | 湖南省衡东县 |
| 奖励名称用简称 | 县优秀班主任 | 衡东县优秀班主任（以通知全称为准） |
| 多余标点/空格 | 参加工作时间， | 参加工作时间 |
| 事迹超字数 | >500 字长文 | 提炼核心事实压缩至 500 字内、第三人称 |

**原则：改错不改义。** 只修错字、规范化名称日期、压缩超限字数；不增删候选人的实质信息。拿不准时保留原样，并在交付时提示用户核对。

## 原表结构定位（脚本依赖）

脚本 `fill_form.py` 基于衡东县通知原表的结构，若模板变化需同步调整：

- 封面字段（姓名/申报奖励名称/工作单位/填报时间）：位于标题段落之后的带下划线空位段落，脚本匹配「去空格后等于字段名」的段落并替换下划线 run 文本。
- 申报表由 3 个表格组成：
  1. **信息表**（23 行 × 10 网格列，含合并单元格）：前 10 行基本信息（逻辑格 1=值1、3=值2），行 11-15 工作简历（逻辑格 1=时间、2=所在单位、3=从事工作），行 17-22 荣誉（逻辑格 1=获奖名称、2=获奖时间、3=授予单位）。
  2. **教学工作量表**（7 行 × 4 列）：行 1-5 为 5 个学年度（逻辑格 2=任教内容），行 6 为先进事迹（逻辑格 1=事迹正文）。
  3. **意见表**（4 行 × 2 列）：本人意见/学校意见/审批意见，属签名盖章栏，通常不填。
