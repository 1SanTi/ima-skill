# 笔记 → 研修总结：结构模板与处理要点

## 一、笔记形态判断

IMA 笔记常见两种形态：

| 形态 | `export_note` 返回 | 获取正文的方式 |
|------|--------------------|----------------|
| 图文笔记 | 完整 Markdown 正文 | 直接读 |
| 录音笔记（含 ` <audio .../> ` 标签） | 只有音频附件 + 图片链接，**正文实为录音** | `fetch(type="note_id")` 拿转录，长录音分块补齐 |

## 二、长录音分块 fetch 法

单次 `fetch` 输出有上限，约 30 分钟以上的录音转录会被截断（保留开头+结尾，中间丢失）。按时间轴切块多次请求：

```
fetch(type="note_id", id=<note_id>, question="请完整逐字输出音频转录中 00:30:00 至 01:00:00 时间段的全部文字（保留时间轴标记与说话内容），不要总结、不要省略")
```

建议切块长度 20–30 分钟。把所有块按时间轴拼回完整原文后再动笔，避免漏掉中间的讲话／讲座要点。

## 三、推荐结构（JSON blocks）

```json
{

  "blocks": [
    {"style": "h1", "text": "一、研修概况"},

    {"style": "h1", "text": "二、研修主要内容"},
    {"style": "h2", "text": "（一）开班仪式：明确方向，凝聚共识"},
```

## 四、领导讲话归纳法

把每位领导的讲话压缩成一个"主题句 + 3 个要点"，例如：

- **校领导欢迎词** → 定位（工作室是"孵化器/生长地/桥头堡"）+ 三点希望（主持人引领 / 成员抱团成长 / 辐射带动）+ 保障承诺
- **分管领导讲话** → 三个"为"（为学生奠基 / 为本地教育加油 / 为自己争光）
- **主管领导总结** → 三方面要求（使命在肩担当于行 / 锚定课堂做实研修 / 凝聚团队做好示范）+ 纪律要求

讲座则按"理念—路径—案例—展望"分条，把落地案例（工具名、应用场景）保留为要点。

## 五、易错点

1. **人名**：转录常出现同一人两三种写法（音近字）。优先用"姓氏＋职务/头衔"，必须写全名时取最可信写法并提示用户核对。
2. **时间**：若无法确定具体日期，用"2026年X月"这类到月的表述，不臆造日期。
3. **不编造**：讲话内容、数据、案例一律来自笔记；概括可以，虚构不行。
4. **标题**：主题要用"活动全称＋研修总结"，不要照搬笔记的简短标题。

## 六、生成与交付

```bash
python3 scripts/build_summary_docx.py summary.json -o "研修总结.docx"
```

生成后用 `provide_file` 交付下载链接。若用户要求，再上传到指定知识库。
