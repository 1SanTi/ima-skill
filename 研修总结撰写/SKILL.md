# 研修总结撰写

把一次研修／培训／开班／讲座活动的笔记（正文常常是一段录音），整理成结构化的研修总结，生成规范排版的 Word 文档并交付下载链接。

## 产出物

- 一份 `.docx`，结构为：研修概况 → 研修主要内容（分环节）→ 研修收获与体会 → 今后努力方向 → 署名
- 交付方式：用 `provide_file` 返回下载链接

## 工作流

### 第 1 步：取到活动原文

- **笔记正文若是一段录音**：`export_note` 往往只返回音频附件与图片的 Markdown，正文其实是录音。此时改用 `fetch(type="note_id", id=<note_id>)` 获取录音的转录文本。
- **长录音会截断**：时长超过约 30 分钟的录音，单次 `fetch` 的输出会被截断（通常保留开头和结尾）。**按时间轴分块多次 fetch**补齐——分别索取 `00:00–00:30`、`00:30–01:00`、`01:00–01:30` …… 的逐字转录，再拼接成完整原文后动笔。分块请求时明确要求"保留时间轴标记、逐字输出、不要总结"。
- 也可用 `export_note` 拿到音频的 cosKey／m4a 下载后解析，但同样受输出上限影响，分块仍是关键。

### 第 2 步：梳理活动要素

从转录中提取并建立"谁讲了什么"的清单：活动名称、时间、地点、主办／承办单位、出席领导与主讲人（姓名＋职务）、主持人、议程环节、各段讲话与讲座的核心要点、关键数据和案例。按时间轴顺序排列。

### 第 3 步：按固定结构成文

默认结构（按活动实际情况微调）：

1. **研修概况**：时间、地点、活动名称、主办方、参加人员、本人身份、一句总起
2. **研修主要内容**
   - （一）开班／开幕环节：领导致辞与讲话精神
   - （二）专题讲座／主题培训：主讲人观点与案例（按主题分点归纳）
3. **研修收获与体会**：3–5 条（思想认识 / 理念更新 / 方法本领 / 责任担当）
4. **今后努力方向**：3 条，可落地
5. **结语** ＋ 署名（总结人、日期）

- 语言：正式书面语、第一人称（参加者视角），全文 2000–3500 字为宜。

### 第 4 步：生成规范 Word

用本 Skill 的 `scripts/build_summary_docx.py`（JSON 驱动）生成，排版规范与 ima-doc 一致：A4；正文宋体＋Times New Roman 12pt、1.5 倍行距、首行缩进 2 字符；标题黑体。

用法：

```bash
# 1) 把内容写成 JSON（结构见 references/note-to-summary.md）
# 2) 生成
python3 scripts/build_summary_docx.py input.json -o "研修总结.docx"
```

JSON 结构（`blocks` 按顺序渲染，`style` 取值：`title` / `h1` / `h2` / `para` / `sign`）：

```json
{
  "title": "云溪县初中物理、初中生物名师工作室联合开班仪式暨\"AI赋能教学教研\"专题讲座研修总结",
  "blocks": [
    {"style": "h1", "text": "一、研修概况"},
    {"style": "para", "text": "……"},
    {"style": "h2", "text": "（一）开班仪式：明确方向，凝聚共识"},
    {"style": "para", "text": "……"},
    {"style": "sign", "text": "总结人：万灵谱尼"},
    {"style": "sign", "text": "2026年9月"}
  ]
}
```

### 第 5 步：交付

`provide_file` 返回下载链接，在回复里用 Markdown 链接展示，并用一两句话说明文档结构与字数。

## 关键经验（踩坑提醒）

- **姓名最易出错**：录音转录常把领导／主讲人姓名听错（同一人前后出现两种写法、音近字）。不必强行确定，可用"某局长／某校长／某老师＋职务头衔"表述；若必须用具体姓名，取转录中首次明确出现且最可信的写法，并在交付时提示用户核对。
- **头衔优先于全名**：主讲人是正高级／首席名师／培训师时，写作"正高级教师王老师"式的"姓氏＋头衔"，既专业又规避姓名错误。
- **忠于笔记**：内容必须来自活动记录，不虚构讲话、数据或案例；概括可以，编造不行。
- **分环节、忌流水账**：领导讲话按主题归纳（如"三点希望""三个'为'""三方面要求"），讲座按观点分条，避免逐句复述。
- **保留干货**：讲座中的落地案例与关键数字（如 AI 批改、情境构建工具、具体应用）是总结的价值所在，应保留要点。
- **笔记标题≠总结标题**：笔记标题（如"生物名师工作坊"）只是索引，总结标题应还原为完整的"活动名称＋文体"。
