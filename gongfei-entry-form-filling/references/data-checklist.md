# 应收集字段清单 & 缺失处理

填写前，把下面字段尽量凑齐。**凑不齐的留空，并列入《待补信息清单》交客户补充——不要臆造。**

## 基本信息（汇总表一般有）
- 姓名 / 性别 / 民族 / 出生年月（可由身份证第7-14位推出）/ 身份证号
- 毕业学校（**注意汇总表里常有两个“毕业学校”列**：前一个是高中毕业学校，后一个是培养院校/大学）
- 所学专业 / 入学年份 / 毕业年份（→毕业时间）/ 培养类型 / 联系方式
- 拟入编单位 / 合同鉴证号 / 序号

## 需要额外向本人确认的（汇总表通常没有）
| 字段 | 追问要点 | 缺失处理 |
|---|---|---|
| 政治面貌 | 中共党员/预备党员/共青团员/群众 | 留空+列清单 |
| 籍贯 | 具体到县（可由住址推） | 留空或按住址推 |
| 户籍所在地 | 市+县 | 按汇总表“户籍所在县市区” |
| 户口性质 | 非农户口/农业户口 | 留空+列清单（登记表勾选） |
| 婚姻状况 | 已婚/未婚 | 留空+列清单（登记表勾选） |
| 参加工作时间 | 应届生常按聘用起始日 | 留空+列清单 |
| 专业技术职称 | 应届/新入职多填“未定级”；委托人说留空则留空 | 按录音；未说则留空 |
| 教师资格证 | 学段（初中/高中）+学科 + **认定（取得）时间** | 填“资格证名称”，取得时间按认定日期 |
| 任教学科 | 如“初中心理教育” | 放“备注”（三表无专列） |
| 简历（从高中起） | 各段起止年月+学校 | 按毕业年份倒推（高中≈大学入学年-3），并在清单注明“已推算待确认” |
| 家庭成员及主要社会关系 | 称谓/姓名/年龄/政治面貌/工作单位及职务（一般父母/配偶/子女） | 缺则留空+列清单；政治面貌不明也留空 |
| 单位联系人/电话 | 单位政工人事 | 缺则留空+列清单 |
| 证件照 | 一寸、蓝底、jpg/png | 无照片则照片栏留空 |

## 冲突与优先级
客户**最新口述录音** > 聊天资料截图 > 汇总表 > 推断。同一字段多处不一致时按此排序并记入本清单说明。

- [ ] 待补清单已包含全部留空项
