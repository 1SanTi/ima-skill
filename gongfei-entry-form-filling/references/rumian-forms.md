# 三份入编表格：结构与字段映射

> 结构基于衡阳市/衡东县 2026 年模板，**不同年度/县区可能微调**。动手前务必先 dump 单元格/网格，确认标签列与值列，再写值。

## 通用（来自“填表说明及要求”）

- **序号**：取《公费师范毕业生汇总表》的序号，写在每张表**右上角**。
- **编制审批表**：“申报（调入）单位意见”填“同意”并盖单位公章；“调入单位主管部门意见”填“同意”由教育局盖章；“县委编办审批意见”**不填**。日期一般 = 聘用起始日（如 2026年9月1日）。
- **登记表**：“聘用单位意见”填“同意聘用”+盖公章；“主管部门意见”填“同意聘用”；“县市区事业单位人事综合管理部门意见”填“同意从X年X月X日聘起”；“事业单位人事综合管理部门意见”**不填**。一式2份、双面打印。
- **花名册**：电子版由单位汇总上报；招聘单位 = 拟入编单位，联系人 = 单位政工人事。
- 各表照片栏可嵌入证件照（个人资料另需电子照 ≤100KB，命名“身份证号+姓名+学校名”）。

## 一、《衡东县机关事业单位人员编制审批表》（xlsx）

原始文件通常有两个 sheet：`模板`（示例，可删）、`空白表`。**用“空白表”填**。

**值单元格（标签列 B/D/F 不可覆盖！值在 C/E/G）：**

| 位置 | 字段 |
|---|---|
| B3（合并 B3:C3） | 申报单位名称（单位全称） |
| E3 | 编制性质（如“全额事业”） |
| B4（合并 B4:I4） | 使用编制进入方式，勾选方式：把 `□` 改成 `√`（公费师范生一般按模板勾，见下） |
| C5 / E5 / G5 | 姓名 / 性别 / 出生年月 |
| C6 / E6 / G6 | 身份证号码 / 民族 / 籍贯 |
| C7 / E7 / G7 | 参加工作时间 / 政治面貌 / 学历 |
| C8 / E8 / G8 | 所学专业 / 职（务）称 / 原工作单位 |
| B9（合并 B9:I14） | 拟进人员简历（需 `wrap_text=True`、left、top） |
| B15（合并 B15:I15） | 拟进理由（如“2026年公费师范生毕业分配”） |
| A21（合并 A21:C21）/ A23 | 申报（调入）单位意见“同意” / 日期 |
| D21（合并 D21:F21）/ D23 | 调入单位主管部门意见“同意” / 日期 |
| H5（合并 H5:I8） | 照片栏（约 3.5cm×4.2cm；插图前把占位文字“近期一寸彩色照片”清空） |

- 使用编制进入方式：2026 年模板在 **⑩其他** 处打 √；旧样例曾用 **②招聘√**。**以当年模板为准，不确定时列入待确认。**
- 应届毕业生：职（务）称、参加工作时间、原工作单位常**留空或填“无”**——按录音/说明；原工作单位一般“无”。
- 身份证 18 位，C6 列较窄，建议设 `shrink_to_fit=True` 或让其居中折行。

## 二、《衡阳市事业单位新进编人员登记表》（docx，含 2 个表格）

**表1（11 行 × 12 列，网格列从 0 起）——值写在标签右邻单元格：**

| 行 | 网格列 → 值 |
|---|---|
| 0 | (1)姓名 (5)性别 (8)民族；[10~11]为照片（跨行0-3） |
| 1 | (1)出生年月 (5)政治面貌 (8)籍贯 |
| 2 | (1)户籍所在地 (5)户口性质（勾选） (8)婚姻状况（勾选） |
| 3 | (1)身份证号码 |
| 4 | (1)学历 (5)学位 (9)毕业院校、专业及时间（left） |
| 5 | (4)专业技术职务任职资格（应届常留空） (11)取得时间 |
| 6 | (4)执业资格（如教师资格证） (11)取得时间 |
| 7 | (2)曾受过何种奖励或处分（常“无”，left） |
| 8 | (2)聘用单位 (9)单位性质 |
| 9 | (2)聘用岗位类别：把“专业技术岗位□”的□改√ |
| 10 | (2)简历（从高中起，left，可多行） |

**表2（16 行 × 7 列）：**

| 行 | 内容 |
|---|---|
| 0 | 表头：家庭成员及主要社会关系 / 称谓 / 姓名 / 年龄 / 政治面貌 / 工作单位及职务 |
| 1~9 | 家庭成员数据行：值在网格列 (1)称谓 (2)姓名 (3)年龄 (4)政治面貌 (5)工作单位及职务 |
| 10~11 | 考试成绩：笔试(2~3) 面试(4~5) 总成绩(6) |
| 12 | 体检结果(2~3) / 考核结果(4~5) |
| 13 | 聘用单位意见(1~3)=“同意聘用” / 主管部门意见(5~6)=“同意聘用” |
| 14 | 县市区事业单位人事综合管理部门意见(1~3)=“同意从…聘起” / 事业单位人事综合管理部门意见(5~6)不填 |
| 15 | 备注(2~6)（可放“任教学科：…”等无专栏信息） |

- 照片栏：表1 第 0 行第 10 列起、跨 4 行 2 列的合并单元格，约 **2.67cm × 4.37cm**；插照片用 `Cm(2.3)×Cm(3.45)` 一般不会撑高行。
- 表2 第 2 行第 4 列有时残留一个“·”，是模板原有，可忽略或清理。

## 三、《衡阳市事业单位聘用人员花名册》（docx，横向 A4）

- 标题下有行：`招聘单位：` `联系人：` `联系电话：` `年 月 日`（招聘单位=拟入编单位；联系人=单位政工）。
- 表格：第 0、1 行为表头（第1行第9列把“职称、执（职）业资格”拆成两行）；**数据行从第 2 行起**：序号/姓名/性别/出生年月/政治面貌/学历/学位/毕业学校/所学专业/职称、执（职）业资格/聘用岗位/备注；末 2 行为签章栏。
- 第 9 列“职称、执（职）业资格”**要同时写职称与资格**，如“未定级  初中心理教师资格证”（参照模板样例“中小学二级教师 高中英语教师资格证”）。
- 单人单位：**删掉多余空白数据行**可使其落在 1 页。

## 常见坑

1. **xlsx 覆盖标签列**：值写到 C/E/G，别写 B/D/F。
2. **照片撑大行高**：图片高度必须 ≤ 单元格内径。
3. **勾选栏**：直接改单元格/单元格文本（把 `□` 换成 `√`），不要新增控件。
4. **字体**：写值 run 显式设 `w:eastAsia='方正仿宋简体'`、字号 12pt（`sz=24` 半磅）。
5. **CRC 坏文件**：微信/WPS 导出的 docx 读取时可能 `BadZipFile`，临时 patch `zipfile.ZipExtFile._update_crc` 后读。
6. **打印**：登记表 2 页→双面；编制审批表 1 页。
