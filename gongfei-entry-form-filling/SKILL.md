# 公费师范生入编表格填写

帮基层学校/教师把一批“公费师范生（新教师）入编”资料，按当地填表说明逐栏填好，并打包交付。产出物是**填好的表格文件**，不是“教怎么填”的说明。

## 何时用

- 用户给出“入编资料/填表说明” + “人员汇总表” + 个人资料（PDF/截图）+ 口述录音 + 证件照，要求“帮 X 填好这些表格”。
- 典型文件：`1.填表说明及要求.docx`、`2.模板.docx`（多为图片样例）、`3.编制审批表(空白表).xlsx`、`4.新进编人员登记表.docx`、`5.聘用人员花名册.docx`、`6.公费师范毕业生汇总表.xls`。

## 输入类型与解析方式

| 输入 | 常见格式 | 怎么读 |
|---|---|---|
| 填表说明及要求 | docx | `fetch` 全文提取；提取“哪栏填什么、哪栏不填、日期、盖章、份数、序号要求” |
| 人员汇总表 | xls/xlsx | Python `xlrd`/`openpyxl` 按姓名定位整行；含身份证号可推出生年月 |
| 个人资料 | pdf / 图片 / 聊天截图 | `fetch` 提取；聊天截图要按问答逐条抠出（政治面貌、户口、家庭成员、联系人电话等） |
| 口述录音 | mp3/m4a | `fetch` 直接转录，逐条记录“某栏填什么”的口头指令 |
| 证件照 | jpg/png | 用于嵌入表格照片栏 |

## 工作流

**Phase 0 · 读取全部输入** — 用 `fetch` 并行读取说明、汇总表、资料、照片，用 Python 读 xls/xlsx 汇总表。录音先转录。

**Phase 1 · 归并数据** — 以“人”为单位建一个数据字典。**冲突处理优先级：客户最新口述 > 聊天资料 > 汇总表 > 推断**。汇总表没有、资料没有、录音没说 → **留空**，不要臆造。

**Phase 2 · 定位当事人 + 序号** — 从汇总表按姓名匹配整行，取出**序号**（按要求写在每张表右上角）与合同鉴证号。

**Phase 3 · 逐表填写** — 三份表逐栏填，**必须在原表上改、保持原格式**（合并单元格、字体、边框、行高全部不动）。字段位置见 `references/rumian-forms.md`。可复用 `scripts/fill_entry_forms.py`（数据驱动）。

**Phase 4 · 嵌入证件照** — 按照片栏单元格内径**等比缩放**、居中插入。**图片不得超过单元格内径**，否则 Word 行高被撑大、改变表格尺寸（用户明确要求“不改表格大小”）。见 `references/rumian-forms.md` 的照片栏尺寸。

**Phase 5 · 生成待补清单** — 生成一份《填写说明及待补信息》docx：写清已填内容、需客户补充项、盖章/签字/序号位置。缺项一律列进去。

**Phase 6 · 校验与打包** — 转 PDF 渲染逐页 OCR 复核（有无串栏、漏填、照片变形）；打包 zip；`provide_file` 交付（用户看不到沙箱文件）。

## 确认门（重要）

- Phase 1 结束后，若关键字段缺失（政治面貌/户口性质/参加工作时间等），**先在表格留空**，把待确认项一次性列给用户/客户，**不要猜**。
- 覆盖/删除用户上传的原件前必须确认。
- 表格中“选择类”栏（户口性质、婚姻状况、岗位类别等）没有确凿信息时留空 + 列清单，不要勾。

## 规则（为什么）

- **xlsx 值列常与标签列相邻错位**：编制审批表标签在 B/D/F 列，值在 C/E/G 列；写错列会覆盖标签、毁掉整表。先 dump 单元格确认标签列再写值。
- **照片必须等比且小于单元格内径**：否则行高变化 → 表格尺寸改变。
- **正文统一字体**：登记表/花名册多用“方正仿宋简体”+Times New Roman、12pt；写值 run 需显式设 `w:eastAsia`。
- **微信/WPS 导出的 docx** 图片常有坏 CRC，python-docx 读取会报 `BadZipFile`，需临时关闭 zip CRC 校验再读。
- **同一文件不要并行 file_edit**（读写竞态会丢改动），串行改并逐次校验。
- 表单“无对应栏目”的信息（如任教学科）**放进“备注”栏**并说明。
- **多轮增量更新**：委托人常分多次补录音/资料（如先给基本信息、后给职称与教资认定时间）。每次都要**在原已填表格上继续改**，改完重新比对模板与填表说明、重新打包，并同步更新本技能。
- **新入职常见值**：职称/职务“未定级”；参加工作时间取聘用起始年月；教师资格证取得时间按认定日期。

## 脚本

- `scripts/form_fill_utils.py` — 通用工具：`set_docx_cell`（保格式写值）、`grid_cell`（按网格列定位合并单元格）、`insert_photo_fit`（等比适配单元格插图）、openpyxl 写值/插图。
- `scripts/fill_entry_forms.py` — 数据驱动：读 `data.json` 填三表并可选打包。文件头有用法与 data.json 结构。
- `references/rumian-forms.md` — 三表逐栏结构与字段位置、照片栏尺寸、常见坑。
- `references/data-checklist.md` — 应收集字段清单与缺失处理。

## 示例

**示例 1（完整）**：2026 年衡东县公费师范生罗华昌。输入含填表说明、汇总表（第43号）、聊天截图资料、多段口述录音、证件照；产出编制审批表 xlsx、登记表 docx（2页双面）、花名册 docx（单页）、待补清单 docx，打包 zip。要点：政治面貌共青团员、农业户口、未婚、学历本科/学士；职称/职务“未定级”、参加工作时间“2026.09”、教师资格证“初中心理教师资格证、认定时间 2026年7月10日”、任教学科入备注；父母政治面貌“群众”；花名册联系人取单位政工（侯志强）。照片嵌入两表且不改表格尺寸。

**示例 2（信息不全）**：只给填表说明 + 汇总表。此时只能填姓名/性别/民族/出生年月/身份证/学历学位/毕业院校专业/单位/岗位等汇总表已有项；政治面貌、籍贯、户口性质、婚姻状况、家庭成员、资格证等一律留空，产出一份待确认清单交用户去问客户。**不要为了“填满”而编造。**
