# 校园新闻稿撰写与归档

## 概述

面向中小学教师（默认青竹中学 / 通讯员万灵谱尼）的校园活动新闻稿助手。产出一篇**格式规范、语言生动、篇幅精简**的新闻稿 Word 文档（可配现场照片），并按需存入个人知识库分类归档。

## 核心格式规范（固定，勿随意更改）

排版沿用用户既有稿件风格，由 `scripts/generate_news.py` 自动应用，无需手调：

| 元素 | 字体 | 字号 | 对齐 | 说明 |
|------|------|------|------|------|
| 主标题 | 宋体 | 16pt | 居中 | 用中文双引号包裹，如“金秋启新程，逐梦正当时” |
| 副标题 | 宋体 | 16pt | 右对齐 | “——”加校名＋活动名称 |
| 正文 | 宋体 | 14pt | 左对齐 | 三段式 |
| 配图 | — | — | 居中 | 宽度约 12cm，正文后、落款前 |
| 落款 | 宋体 | 14pt | 右对齐 | “通讯员：万灵谱尼” |

## 三段式结构（正文固定三段）

1. **第一段（概貌）**：时间＋主体＋活动概况——何时何地、谁组织、做了什么、谁主讲/主办。
2. **第二段（过程）**：活动过程的细节与画面——具体动作、关键环节、人物话语，让读者“看得见”现场。
3. **第三段（升华）**：现场气氛＋活动意义——收束情绪、点明成效与展望。

正文总篇幅控制在约 200–280 字，与用户既有稿件持平，宁简勿繁。

## 语言风格（重要）

- **要生动、有画面感、有特色**，多用手法：细节动作、人物话语、现场声音、比喻。
- **避免公文套话**，如“隆重举行”“切实增强”“奠定了坚实基础”“增强了意识”“进一步提升了”。
- 参考既有稿的笔法，例如：
  - “课堂在‘镜子模仿秀’的欢声笑语中破冰启航”
  - “如春风化雨般助力学子健康快乐成长”
- 完整范例见 `references/examples.md`，动手前先读一遍，把握语气后再落笔。

## 工作流程

### Phase 1：读取素材
- 有参考新闻稿（docx）时，用 `fetch` 提取其格式与字数作为对标；无参考稿则直接采用上述固定格式。
- 有录音（mp3）、图片（jpg）等素材时，用 `fetch` 提取关键信息：时间、地点、人物、讲话要点、现场画面。

### Phase 2：确认关键事实
- 活动时间、地点、参与对象、主讲/主办方等事实务必以素材为准，不要臆造。
- **多图场景先跟用户确认图片归属**（哪张图配哪篇稿），避免放错返工。

### Phase 3：撰写并生成 Word
1. 按三段式结构＋语言风格要求撰写正文。
2. 用 `file_write` 把内容写成 JSON 配置文件，再用脚本生成（中文长文本勿用 shell 直接传参，易因引号转义出错）：

```bash
python3 scripts/generate_news.py --config /sandbox/workspace/news.json
```

JSON 结构见 `scripts/generate_news.py` 顶部注释。生成后确认文件已产出。

### Phase 4：知识库存档
1. 加载 `ima-knowledge` skill 获取上传方法。
2. 在用户个人知识库（默认「三体的知识库」）中新建文件夹分类（如“校园新闻稿”），获取 folder_id。
3. 用 `upload_file.py` 上传文档与照片到该文件夹。
4. 注意：知识库不支持接口删除，重传会产生旧文件残留，需在回复中明确提示用户手动清理旧版。

## 确认门

- 用户提供了多张图片、或图片内容性质不明时，先确认图片与新闻稿的对应关系。
- 需要修改时，重新生成文档并提示用户删除旧版文件。
