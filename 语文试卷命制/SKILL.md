# 语文试卷命制

依据命制要求，结合课程标准、教材、授课课件、命题素材与最新时事，生成一套"有据可依、情境统领、规范排版"的语文试卷，并配套参考答案、命制思路报告、专项训练，最后分类归档到个人知识库。

> **核心原则**
> 1. **有据可依**：每一道题都要能对应到课标要求、教材知识点或单元学习目标，不命制"为考而考"的偏题怪题。
> 2. **大情境统领、任务群组织**：语文"活动·探究"单元（如新闻、演讲、诗歌）务必做到"一境到底"，用任务群串联题型。
> 3. **参考排版、不参考内容**：用户提供的参考试卷只取其排版格式（大题编号、分值标注、选项排布、表格、参考答案附后），内容必须原创。
> 4. **融入最新时事**：先确定大情境主题，再筛选合适的最新时事素材，不合适的不用。
> 5. **原创命题**：不照搬素材原题、不整段搬运受版权保护的教材或题库内容；时事新闻的客观事实可引用，但题干、问法须原创。
> 6. **读写闭环**：凡有"采访/实践"环节，必须给出原始素材（如采访对话记录），写作题必须建立在采访所得之上，不可让学生凭空写。

## 适用场景

| 用户意图 | 说明 |
|---|---|
| 按笔记/文档命制要求出卷 | 用户指定"命制要求"笔记或文档时，严格按其中题型、题量、时间、流程执行 |
| 命制单元卷/期中卷/期末卷 | 覆盖一个单元或多个单元，需明确范围、分值、时长、难度比例 |
| 大单元情境化试卷 | 活动·探究单元，用大情境 + 任务群统领（新闻、演讲、诗歌等） |
| 专项训练 | 针对单一能力点（如新闻语言对比、文言实词、古诗鉴赏）单独出题 |
| 试卷修订 | 依据教师修改意见（如增镜头感、补原始素材、加对比题）迭代 |

## 工作流程

### Phase 1 需求采集（先读命制要求）

读 [`references/intake-form.md`](references/intake-form.md)，明确并补齐以下信息：

- 学段、年级、学科、教材版本
- 命制要求（若用户给了笔记/文档，先 `fetch` 完整读取）：题型、题量、时间、设计参考、命制流程
- 范围（单元/章节）、用途（测验/考试/专项）、总分与时长
- 用户提供的素材：教材 PDF、课标、课件 PPT、命题素材、参考试卷、时事链接
- 是否要命制思路报告、参考答案、专项文档、是否归档

缺少关键项时，按"最少追问"补齐，不凭空猜测。

### Phase 2 课标分析

`fetch` 课程标准，提取与命题范围相关的：学段课程目标、学习任务群内容要求、学业质量标准、表达与交流要求。写进命制报告，作为"根本依据"。

### Phase 3 教材分析

`fetch` 教材对应单元，提取：单元导读、学习目标（活动任务单）、课文与体裁、核心知识点、能力要求。尤其注意**活动·探究单元**的"任务一/二/三"结构。

### Phase 4 课件与参考试卷分析

- `fetch` 授课课件，提取大单元主题、任务群设计、情境设置、知识点、活动环节。
- `fetch` 参考试卷，提取排版格式（大题中文编号、小题数字、分值标注位置、选项排布、表格、参考答案位置），**不参考其内容**。

### Phase 5 时事素材筛选 + 大情境设计

- 从用户提供的最新时事链接/新闻中筛选，按"国事/天下事/家事"或主题逻辑归类，确定大情境主题。
- 时事素材要"能对应体裁"：消息（时效强、要素完整）、特写（有瞬间与细节）、通讯（有故事与人物）、评论（有观点）。

### Phase 6 命制思路框架报告

按 [`references/report-template.md`](references/report-template.md) 撰写，内容要丰富：课标分析、教材分析、学情与目标融入、大情境设计、素材选取说明、命题蓝图、依据对应表。

### Phase 7 命制试题

按 [`references/blueprint-template.md`](references/blueprint-template.md) 先定蓝图，再逐题命制：

- **材料必须完整**：阅读材料要给整篇新闻（标题、导语、主体、结语齐全），不能只给节选片段——学生读不完整就无法真正作答与对比。
- 题号全卷连续编号（不要每个任务群都从"1"重新开始）；分值加总须等于满分。
- 纯知识选择题（定义、六要素、体裁等）放"知识闯关"板块；涉及具体材料的语言/体裁题放"阅读"板块，避免重复。
- 新闻/实用类文本阅读：材料可适当删改但**保留关键事实**；特写要"还原镜头感、以描写为主"；通讯要"细节+情感"；评论要"事实与观点分明"；可考察语言"客观准确 vs 主观态度"的双重特点。
- 采访/实践：**必须给真实、完整的原始素材**（可上网搜真实采访案例），再让学生补提纲、写一句话新闻；素材太少或虚构会让学生无从下笔。
- 写作题：与采访/实践**闭环**，明确"据采访所得写"，并预留答题横线。

### Phase 8 参考答案与评分标准

每题给答案、解析、考查目标、课标/教材依据；主观题给评分要点而非唯一死答案；写作题给分维度表。

### Phase 9 生成 Word 文档

参考排版格式生成 Word（可用 `python-docx`），处理标题层级、表格、加粗、选项、参考答案附后。生成：试卷、参考答案、命制报告、专项文档（如有）。

**答题横线与表格行高（最易被忽略，务必处理）**：
- 写作题、简答题要预留**答题横线**：用段落底边框（`w:pBdr`/`w:bottom`）逐条生成，或 md 中用"整行全角空格"标记、脚本转成横线。
- 识别"全角空格行"要基于**未 strip 的原始行**：`str.strip()` 会把全角空格一起去掉，若先 strip 就会把横线行当空行丢弃。
- 采访提纲等表格要**加大行高**（如 600 twips ＋ `hRule=atLeast`），否则横线太短、学生写不下。
- 生成后**逐项校验**：横线条数、表格数、题号连续、分值加总。

### Phase 10 知识库分类归档

用 `ima-knowledge` skill：
1. `search_knowledge_base` 定位目标知识库（核对 kb_id 与名称一致）。
2. `create_folder` 建立"年级＋学科"顶层文件夹、"单元＋专题"子文件夹。
3. `upload_file.py --folder-id` 上传文件。
4. 修订版用 `--rename` 加"（修订版）"区分；旧版用 `move_knowledge` 移到"旧版归档"子文件夹（API 不支持删除，需提醒用户可在客户端手动删除）。

## 关键经验（来自实战）

- **材料必须完整**：阅读材料要给整篇新闻，不能只给节选句子。片段化会让学生"读不懂、答不出、对比不了"，是最常见的返工点。
- **采访必须有真实、完整的原始素材**：只让学生"写采访提纲"却不给采访内容，学生无从下手。素材要真实（可上网搜真实采访案例）且内容充实，提纲补写、一句话新闻、新闻写作都基于它。
- **特写要"镜头感"**：删改特写时若只剩"结果性叙述"（比分、用时），会退化成消息。要保留/补入动作、神态、细节描写，以描写为主。
- **知识点与阅读分家**：纯知识选择题放"知识闯关"，涉及具体材料的题放"阅读"，避免重复。
- **体裁谱系要齐**：消息/特写/通讯/评论最好各取一则真实新闻，构成完整体裁谱系；语言特点可另建"对比专项"，四则材料各挑典型句，出连线、赏析、事实vs观点、综合对比、迁移写作题。
- **答题横线与表格行高要够用**：写作、简答、表格都要预留足够书写空间，生成 Word 后逐项校验。
- **参考素材常单列**：用户可能把时事新闻等命制参考素材集中放在"参考命制"文件夹，命题时从中取材。
- **旧版归档**：知识库 API 不支持删除，修订版先移旧版到"旧版归档"再上传（避免重复堆积），并提醒用户可在客户端手动删除。
