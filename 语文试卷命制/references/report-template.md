# 命制思路框架报告模板

报告要"内容丰富"，是命制习题前的依据说明。建议结构如下：

```markdown
# {年级}{单元}大单元情境化试卷——命制思路框架报告

> 命题人：{姓名}｜适用：{教材版本}｜命制时间：{日期}

## 一、课程标准分析（命题的根本依据）
- 发展型学习任务群（如"实用性阅读与交流"）相关要求
- 学段要求（阅读与鉴赏、表达与交流）
- 学业质量标准相关表述
- 命题转化结论（一句话）

## 二、教材分析（{单元}）
- 单元性质（如"活动·探究"单元）
- 单元课文与体裁（表格）
- 核心知识点（表格或列表）
- 单元能力要求

## 三、学情与学习目标的融入
- 学情简析
- 目标维度表：知识 / 阅读 / 实践 / 表达 → 对应任务群
- 目标融入原则

## 四、大情境设计
- 情境主题、情境描述
- 任务群分解（任务群一/二/三/四…）
- 情境设计意图

## 五、素材选取说明
- 时事素材表：素材 / 体裁定位 / 选取理由
- 未选用素材说明

## 六、命题蓝图
- 考试时间、满分、难度比例
- 蓝图表：任务群 / 题型 / 题量 / 分值 / 知识点 / 能力层级
- 原创方式说明

## 七、命制依据对应表（"每一题都有据可依"）
- 题号 / 考查点 / 课标·教材依据 三列表
```

## 写作要点

- 每一节都要落到"这套题为什么这么出"，不写空话。
- "依据对应表"务必逐题列出，证明有据可依。
- 难度比例、分值要能加总校验（如 18+14+11+11+10+36=100）。
