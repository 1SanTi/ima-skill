# 需求采集表

命制前先补齐以下信息。用户给了"命制要求"笔记/文档时，先用 `fetch` 完整读取，再对照本表补齐缺口。

## 必填项

| 项目 | 说明 | 示例 |
|---|---|---|
| 学段与年级 | 七/八/九年级 | 八年级上册 |
| 学科与教材版本 | 统编版（人教版）等 | 统编版语文 |
| 命制范围 | 单元/专题/整册 | 第一单元"新闻" |
| 题型与题量 | 明确各题型数量 | 选择题6道、阅读3则、采访2题、写作1题 |
| 时间与总分 | 考试时长、满分 | 45分钟、100分 |
| 用途 | 测验/考试/专项训练 | 单元情境化检测 |

## 用户可能提供的素材（逐一 `fetch` 读取）

- [ ] 命制要求（笔记 note_id 或文档）
- [ ] 课程标准 PDF
- [ ] 教材 PDF
- [ ] 授课课件 PPT
- [ ] 命题素材 PDF
- [ ] 参考试卷（只取排版格式）
- [ ] 最新时事链接/新闻（融入情境）

## 命制要求常见要点（若有笔记，逐条核对）

1. 题型是否要求"大情境统领、任务群组织"？
2. 是否有"采访/实践"环节？是否要求给原始素材、与写作闭环？
3. 是否要求"参考排版、不参考内容"？
4. 是否要求"融入最新时事"？
5. 是否要求"先写命制思路报告、再命制"？
6. 是否要求"每题有据可依"（对应课标/教材/目标）？
7. 是否要求"把流程写成通用 skill"？

## 最少追问（信息不足时最多问 3 个）

1. 学段、年级、学科、教材版本。
2. 命制范围（单元/知识点）与题型、题量、分值、时长。
3. 是否有命制要求笔记/参考试卷/时事素材需要参考。

- [ ] 参考答案与评分标准
- [ ] 专项训练文档（如有）
- [ ] 归档到知识库（哪个知识库、如何分类）
