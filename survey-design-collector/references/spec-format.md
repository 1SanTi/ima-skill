# questions.json 规格说明

问卷的所有内容都写在一个 JSON 文件里。改这个文件即可换问卷。

## 顶层字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 问卷标题，如“教师人工智能（AI）认知调查问卷” |
| `subtitle` | 否 | 副标题，如“——××学校” |
| `intro` | 否 | 卷首语（说明语）。用 `\n` 换行 |
| `footer` | 否 | 结束语 |
| `scale_options` | 否 | 量表题统一档位，默认 `["非常清楚","比较清楚","一般","不太清楚","完全不清楚"]` |
| `sections` | 是 | 板块数组，每个板块含 `title` 和 `questions` |

## 题目字段（questions[]）

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | 唯一标识，如 `q1`、`q2`（用于存库，勿重复） |
| `type` | 是 | `single` 单选 / `multi` 多选 / `scale` 量表 / `text` 填空 |
| `title` | 是 | 题干 |
| `required` | 否 | `true` 表示必答 |
| `options` | 选项题必填 | 选项数组 |
| `options_scale` | 否 | 设为 `true` 时，选项取顶层 `scale_options`（等价于 `type:"scale"`） |
| `allow_other` | 否 | `true` 时自动追加“其他（请注明）”+ 文本框 |
| `exclusive` | 否 | 互斥选项数组，如 `["都没有使用过"]`（选了它就不该选别的，仅作语义标注） |
| `placeholder` | 否 | 填空题占位提示 |

## 完整示例

```json
{
  "title": "教师人工智能（AI）认知调查问卷",
  "subtitle": "——××学校",
  "intro": "尊敬的老师：\n您好！本问卷……预计用时 3—5 分钟。",
  "footer": "问卷到此结束，感谢您的参与！",
  "scale_options": ["非常清楚", "比较清楚", "一般", "不太清楚", "完全不清楚"],
  "sections": [
    {
      "title": "第一部分　基本信息",
      "questions": [
        {"id": "q1", "type": "single", "title": "您任教的学段是", "required": true,
         "options": ["小学", "初中", "高中（含中职）"]},
        {"id": "q2", "type": "multi", "title": "您任教的学科是（可多选）", "required": true,
         "allow_other": true, "options": ["语文", "数学", "英语", "其他"]},
        {"id": "q3", "type": "single", "title": "您的教龄是", "required": true,
         "options": ["1—5 年", "6—10 年", "11—20 年", "20 年以上"]}
      ]
    },
    {
      "title": "第二部分　对人工智能的了解与认知",
      "questions": [
        {"id": "q4", "type": "multi", "title": "您使用过哪些 AI 工具？（可多选）",
         "required": true, "allow_other": true,
         "options": ["DeepSeek", "豆包", "Kimi", "WPS AI", "都没有使用过"]},
        {"id": "q5", "type": "scale", "title": "您对 AI“相关术语”的了解程度如何？", "required": true},
        {"id": "q6", "type": "text", "title": "您对 AI 在教学中应用的看法或建议？", "required": false,
         "placeholder": "请在此填写（选填）"}
      ]
    }
  ]
}
```

## 从录音/口述转成问卷的方法

1. **先通读转录稿**，找“板块/维度”线索（如“第一个模块是……”“第二个方面是……”）。
2. 把口语化的表述**改写成书面题干**，例如：
   - 口述“你平常都用哪些人工智能的工具啊”——→ 题干“您平时使用过或了解过下列哪些人工智能工具？”（多选）
   - 口述“术语清不清楚”——→ 题干“您对人工智能相关术语的了解程度如何？”（量表）
3. 为每个维度**补齐选项**：工具类可列常见工具 + “都没有使用过” + “其他”；程度类统一用五级量表。
4. 判断**题型**：让老师“投票/勾选”→ 多选；问“是否清楚/程度”→ 量表；要一句话建议 → 填空。
5. 组稿后**自检**：题号连续、选项穷尽互斥、必答标记合理、整体 3—5 分钟可完成。
