# 在线问卷系统 · 使用说明

一套「手机扫码答题 + 后台数据自动汇总」的问卷系统，**零第三方依赖**（只用 Python 自带的库），
拷到任何一台电脑上都能直接运行。

---

## 一、三步开始使用

### 第 1 步：确认电脑装了 Python 3
- Windows：到 [python.org](https://www.python.org/downloads/) 下载安装，安装时**务必勾选 “Add Python to PATH”**。
- Mac / Linux：系统一般自带，或终端运行 `python3 --version` 检查。
- 检查是否装好：命令行输入 `python3 --version`（Windows 可试 `python --version`），能显示版本号即可。

### 第 2 步：启动系统
- **Windows**：双击 `启动_Windows.bat`
- **Mac / Linux**：双击 `启动_Mac_Linux.sh`（或终端执行 `python3 server.py`）

启动后，窗口里会显示两个网址：
```
老师答题：  http://192.168.x.x:8000/
数据后台：  http://192.168.x.x:8000/admin
```
并会自动打开「数据后台」页面。

### 第 3 步：让老师扫码答题
- 打开**数据后台**页面（`.../admin`），页面顶部会显示一个**二维码**，老师用手机扫一扫即可答题。
- 答题数据和统计结果会自动出现在后台，无需任何手工整理。

> ⚠️ 使用期间**不要关闭那个命令行窗口**，一关服务就停了。

---

## 二、后台能看什么（数据汇总）

打开 `http://电脑IP:8000/admin`：

| 区域 | 内容 |
|------|------|
| 顶部指标 | 答卷总数、今日新增、最早/最近提交时间 |
| 答题入口 | 答题网址 + 二维码（可改成对外公布的网址重新生成） |
| 各题统计 | 每道题自动生成条形图：各选项的**人数**与**百分比**；填空题显示全部文字内容 |
| 答卷明细 | 每一份答卷逐条列出（时间 + 各题答案） |
| 导出 | 点右上角「导出 Excel(CSV)」，用 Excel 打开即可做进一步分析 |

后台每 30 秒自动刷新一次，也可点「刷新数据」立即刷新。

## 三、老师怎么访问？（重要）

### 方式 A：同一个 WiFi / 局域网（最简单，适合校内）
1. 在一台电脑上启动系统（这台电脑就是“服务器”），保持开机、不关窗口。
2. 老师手机连**同一个 WiFi**，扫后台里的二维码即可答题。
3. 若手机打不开：多半是**电脑防火墙**拦了，允许 Python 通过防火墙即可（见下方“常见问题”）。

### 方式 B：公网访问（老师不在同一网络时用）——推荐用于正式发放
本地部署的二维码指向的是**内网地址（192.168.x.x）**，**只有连同一个 WiFi 才能打开**；老师在外地、用流量就会"打不开"。
要让**任意网络**的老师都能扫码答题，需要给它一个**公网地址**，三种做法（详见 `部署到公网/` 文件夹）：

1. **部署到云服务器（最稳，推荐）**：买一台轻量云服务器 → 一键脚本部署 → 永久公网可用、无需本机开机。
   见 `部署到公网/云服务器部署指南.md`。
2. **内网穿透（最快，应急）**：本机运行 + 一键分享脚本（免下载免注册）或 cpolar，几分钟得到公网地址（本机需开机）。
   见 `部署到公网/内网穿透快速方案.md`；Windows 直接双击 **`公网分享_Windows.bat`**。
3. **用现成问卷平台过渡**：时间紧时可先把题目录入腾讯问卷/问卷星，见 `../应急方案_用现成问卷平台.md`。

> ✅ 系统会**自动识别访问地址**：无论你用公网 IP、域名还是穿透地址打开后台，二维码都会指向正确的公网网址；
> 也可用环境变量 `PUBLIC_URL=https://你的域名/` 强制指定。
> 公网部署后如仍打不开，多半是**服务器安全组/防火墙没放行端口**——见 `部署到公网/故障排查_常见问题.md`。

## 四、修改题目 / 换一份问卷

题目全部写在 **`questions.json`** 里，用记事本打开即可修改（保存时选 UTF-8 编码）。
- 改完**重启**系统（关掉窗口重新启动）即生效。
- 题型说明：
  - `"type": "single"` 单选　`"type": "multi"` 多选　`"type": "scale"` 量表　`"type": "text"` 填空
  - `"required": true` 表示必答
  - `"allow_other": true` 会多出一个“其他（请注明）”
  - 量表选项统一取 `scale_options` 字段
- 若只想换标题、卷首语，直接改 `title`、`intro` 即可。

---

## 五、数据存在哪？怎么备份？

- 所有答卷都保存在 **`data/responses.db`**（SQLite 数据库文件）。
- **备份**：直接复制这个文件即可；换电脑时把整个文件夹拷走，数据一起带走。
- 想**清空重来**：关闭服务，删除 `data/responses.db`，再启动即可（会重新建库）。

## 六、常见问题

**1. 手机扫码打不开网页？**
- 确认手机和电脑在**同一个 WiFi**；
- Windows 首次启动时弹“防火墙”提示，请选**允许访问**；
- 或手动放行：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾选 Python。

**2. 提示端口被占用（Address already in use）？**
- 说明 8000 端口已被别的程序用了。可换端口启动：
  - Windows：`set PORT=8080 && python server.py`
  - Mac/Linux：`PORT=8080 python3 server.py`

**3. 电脑重启后 IP 变了，二维码失效？**
- 局域网 IP 由路由器分配，可能会变；到后台按新 IP 重新看二维码即可。
- 想让 IP 固定：在路由器里给这台电脑绑定固定 IP（DHCP 静态分配）。

**4. 想要访问密码？**
- 启动前设置环境变量 `ADMIN_PWD=你的密码`，之后访问后台需在网址后加 `?pwd=你的密码`。

## 七、目录结构

```
在线问卷系统/
├── server.py            主程序（答题页 + 后台 + 接口）
├── questions.json       问卷题目（改这里换题目）
├── 启动_Windows.bat      Windows 一键启动
├── 启动_Mac_Linux.sh     Mac / Linux 一键启动
├── make_qr.py           单独生成二维码的小工具
├── vendor/qrcode/       内置二维码生成（已随包提供，无需安装）
├── data/responses.db    答卷数据库（自动生成）
└── 使用说明.md          本文件
```
