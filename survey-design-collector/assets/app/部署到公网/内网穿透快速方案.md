# 内网穿透 · 快速方案（不买服务器，最快出公网地址）

> **为什么老师打不开？** 现在二维码里是**内网地址**（`127.0.0.1` / `192.168.x.x`），**只有连同一个 WiFi 才能打开**。
> 要让**任何网络**的老师都能扫码，就得给系统一个**公网地址**。本方案不用买服务器：**你自己的电脑运行系统 + 内网穿透**。

---

## ⭐ 最快：一键公网分享（免下载、免注册，1 分钟）

> 原理：利用 **Windows 自带的 ssh** 连到 serveo.net，自动开一条公网隧道。**不用装任何软件、不用注册**。

**Windows：**
1. 双击 `启动_Windows.bat` 启动系统（确认本机能打开 `http://127.0.0.1:8000`）。
2. 双击 **`公网分享_Windows.bat`**。
3. 稍等约 5—15 秒，窗口里会出现一行：
   ```
   Forwarding HTTP traffic from https://xxxxxxxx.serveousercontent.com
   ```
4. **复制**那段 `https://xxxxxxxx.serveousercontent.com`，在浏览器打开：
   ```
   https://xxxxxxxx.serveousercontent.com/admin
   ```
   （就是在地址后面加上 **`/admin`**）
5. 这个页面上的**二维码就是公网地址**了 —— **发到群里**，全国老师都能扫码答题 ✅

**Mac / Linux：** 双击 `公网分享_Mac_Linux.sh`，其余同上。

**手动命令（等价）：**
```bash
ssh -R 80:localhost:8000 serveo.net
```

> ⚠️ 这个方式走**国际线路**，个别网络可能连不上/偏慢。**连不上就用下面的 cpolar**。

## ⭐⭐ 更稳：cpolar（国内服务，有图形界面）

1. **启动系统**：双击 `启动_Windows.bat`。
2. 访问 **cpolar 官网**，用**手机号注册并登录**；下载 **Windows 客户端**并安装、登录。
3. 客户端里「**隧道管理 → 创建隧道**」：

   | 项目 | 填写 |
   |------|------|
   | 隧道名称 | 问卷（随意） |
   | 协议 | **http** |
   | 本地地址 | **8000** |
   | 域名类型 | **随机域名**（免费） |

4. 在「**在线隧道列表**」复制公网地址，形如 `https://xxxxxxxx.r6.cpolar.top`。
5. 浏览器打开 **该地址 + `/admin`**，二维码即为公网地址，发群即可。

> 首次访问可能出现 cpolar 提示页，点「继续访问」即可。

## ⭐⭐⭐ 备选：cloudflared（需下载，国内可能下不动）

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```
出现 `https://xxxx.trycloudflare.com` 后，打开 `该地址/admin`。

## 用完之后 / 注意事项

- 答题期间，**电脑不要关机**，**系统窗口和穿透窗口都不要关**。
- 数据都存在你电脑的 `data/responses.db`，随时可在后台看统计、导出 Excel。
- 免费隧道**地址会变**：重开后，用**新地址 + `/admin`** 重新拿二维码。
- 想长期稳定、不依赖自己电脑 → 见 `云服务器部署指南.md`。

## 常见问题

| 现象 | 解决 |
|------|------|
| 一键分享窗口很快结束、没出现地址 | 该网络连不上 serveo → 改用 **cpolar** |
| 打开 `/admin` 是空白 | 确认用的是**公网地址**（`https://...`）不是本机 `127.0.0.1` |
| 老师还是打不开 | 把公网地址**原样**发群；确认穿透窗口还在、电脑没休眠 |
| 地址变了 | 重新运行一键分享，拿新地址 +`/admin` 出新二维码 |
