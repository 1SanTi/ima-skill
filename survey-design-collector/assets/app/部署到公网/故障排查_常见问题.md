# 故障排查 · 常见问题

## 一、老师扫码「打不开 / 页面无法显示」

这是**最常见**的问题，按顺序排查：

| 可能原因 | 判断与解决 |
|---|---|
| **① 本地部署，老师不在同一 WiFi** | 二维码里是 `192.168.x.x` 或 `127.0.0.1`，**只有同网段能打开**。→ 改用**公网方案**（云服务器部署 或 内网穿透） |
| **② 服务器防火墙/安全组没放行端口** | 到云控制台【安全组】放行 80 端口（或你用的端口） |
| **③ 电脑防火墙拦了 Python** | Windows 首次启动弹窗选「允许访问」；或手动放行 |
| **④ 二维码里的地址不对** | 到后台把「答题网址」改成正确的公网地址，二维码会自动更新 |
| **⑤ 是 http 不是 https** | 一般不影响；个别环境可用域名 + https |

> 一句话：**"打不开"99% 是因为地址不是公网地址，或端口没放行。**

## 二、我选了某个选项，却还让我填「其他」

这是**旧版本**的 bug（每个选项的提交值被写错），**新版已修复**：
- 请使用**最新交付包**重新部署；
- 新版里「其他」输入框**只有勾选"其他"时才出现**，且没勾"其他"时不会误存。

## 三、提示端口被占用 / 想换端口

- 换端口启动：
  - Windows：`set PORT=8080 && python server.py`
  - Mac/Linux：`PORT=8080 python3 server.py`
- 云服务器部署时：`PORT=8080 bash 部署到公网/install.sh`（记得安全组放行 8080）

## 四、后台怎么加密码？

启动前设置环境变量 `ADMIN_PWD=你的密码`，之后后台网址加 `?pwd=你的密码`
（云服务器上改 `survey.service` 里的 `Environment`）。

## 五、数据存在哪？怎么备份 / 清空？

- 位置：`data/responses.db`（云服务器上是 `/opt/survey/data/responses.db`）。
- **备份**：复制该文件即可；也可在后台「导出 Excel(CSV)」。
- **清空**：停止服务 → 删除 `responses.db` → 重启（会重建空库）。

## 六、怎么改题目？

改 `questions.json`（用记事本，存 UTF-8），保存后**重启服务**即生效。题型说明见 `使用说明.md`。

## 七、微信里打开提示「非官方网页 / 可能不安全」

属正常提示（因为不是微信生态的网页），点「继续访问」即可。若在意，可给域名配 https。

## 八、想在电脑重启后自动运行（云服务器）

`install.sh` 已注册**开机自启**（systemd），服务器重启后会自动运行，无需手动。
