# 部署到云服务器（公网访问 · 最稳）

> 目标：把系统放到一台**有公网 IP 的服务器**上，这样**任何网络**的老师扫码都能答题，数据自动回到后台。
> 适合：希望**长期稳定**使用、不依赖自己电脑开着。

---

## 一、先买一台服务器（约 1 小时，一次性）

1. 打开 **腾讯云** 或 **阿里云** 官网，选「**轻量应用服务器**」（最便宜、最简单）。
2. 配置建议：
   - 地域：就近（如广州/上海）
   - 镜像：**Ubuntu 22.04**（或 24.04）
   - 套餐：**2 核 2G** 起（最低 2 核 1G 也够用）
   - 教师/学生可留意优惠活动，通常一年几十到一百多元。
3. 购买后，记下**公网 IP**（形如 `123.45.67.89`），并设置好 **root 密码**。

---

## 二、登录服务器

在云控制台找到你的服务器 → 点「**登录**」/「**远程连接**」→ 打开**网页终端**（腾讯云叫 OrcaTerm，阿里云叫 Workbench）。
出现 `root@...:~#` 命令行即成功。

---

## 三、把系统传上去（二选一）

**方式 A：网页终端直接上传（推荐，最简单）**
1. 在网页终端里，先把系统打包好的 `在线问卷系统` 文件夹（或 zip）**拖拽/上传**到服务器（多数网页终端支持「上传文件」按钮）。
2. 若上传的是 zip，执行解压：
   ```bash
   cd /opt
   unzip 在线问卷系统.zip    # 没有 unzip 就先执行：apt-get install -y unzip
   ```

**方式 B：用 scp 从自己电脑上传**
在你**自己电脑**的终端里执行（把 IP 换成你的公网 IP）：
```bash
scp -r 在线问卷系统 root@123.45.67.89:/opt/
```

---

## 四、一键部署

```bash
cd /opt/在线问卷系统
bash 部署到公网/install.sh
```
脚本会自动：装 Python → 复制程序到 `/opt/survey` → 注册**开机自启**服务 → 启动 → 打印网址。

---

## 五、放行端口（关键！否则还是打不开）

到云控制台：**防火墙 / 安全组** → 添加规则 → 放行 **80** 端口（TCP，来源 0.0.0.0/0）。
> 这是老师们"打不开"最常见的原因。

---

## 六、完成，发二维码

1. 脚本最后会打印：
   - 老师答题： `http://你的公网IP/`
   - 数据后台： `http://你的公网IP/admin`
2. 在浏览器打开 **`/admin`**，页面上的**二维码会自动是这个公网地址**，把它发到群里即可。

---

## 七、（可选）绑定自己的域名 + HTTPS

1. 买一个域名并**完成实名/备案**（国内服务器必须备案）。
2. 域名解析：添加 A 记录 → 指向你的公网 IP。
3. 之后用域名访问即可；如需 https，安装 Nginx + certbot 申请免费证书。
4. 若有反代，给服务加环境变量 `PUBLIC_URL=https://你的域名/`，二维码会更准确。

---

## 八、（可选）用 Docker 部署

在「在线问卷系统」目录下：
```bash
docker compose -f 部署到公网/docker-compose.yml up -d --build
```

---

## 九、日常运维

| 操作 | 命令 |
|------|------|
| 查看状态 | `systemctl status survey` |
| 重启 | `systemctl restart survey` |
| 停止 | `systemctl stop survey` |
| 看日志 | `journalctl -u survey -f` |
| 数据文件 | `/opt/survey/data/responses.db`（**备份＝复制这个文件**） |
| 更新题目 | 改 `/opt/survey/questions.json` 后 `systemctl restart survey` |

---

## 十、安全建议

- **给后台加密码**：编辑 `/etc/systemd/system/survey.service`，在 `[Service]` 下加一行
  `Environment=ADMIN_PWD=你的密码`，然后执行：
  ```bash
  systemctl daemon-reload && systemctl restart survey
  ```
  之后后台地址改为 `http://你的IP/admin?pwd=你的密码`。
- 定期把 `responses.db` 下载备份。
- 不要把 root 密码告诉无关人员。
